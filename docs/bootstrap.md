# Agent bootstrap

Copy this prompt into your coding agent:

```text
Help me set up an independent poser studio using the free Surge XT instrument. Follow
https://github.com/isnbh0/poser/blob/main/docs/setup.md.
Inspect my environment first, preserve existing work, and ask before actions that need permission.
If I already requested a song, continue into composition; otherwise offer it after setup.
Use my preferences or ask for missing creative direction. Listen only with my permission and
when useful. Export the final song to a new bundle, explain what its analysis shows, and tell me
whether you actually listened to it.
```
